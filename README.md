# Grove’s Pocketknife

**View, convert and work with your files in one place.**

Grove’s Pocketknife is a desktop application for working with pictures, music, videos, documents and many other kinds of files. It brings everyday tasks together in a straightforward interface, with tools described in plain English.

For example, Pocketknife can resize photographs for email, save individual frames from a video, make scanned PDFs searchable, play older music formats, or display the contents of an archive. It also helps you explore less familiar files from older computers and software, without having to track down the original application for every format.

[Visit the website](https://grove.id.au/software/pocketknife/) · [Downloads and release notes](https://github.com/grahamlgrove/groves-pocketknife/releases)

## What can it do?

- **Pictures and photographs:** view many modern and older image formats; resize, crop, rotate and convert pictures; add watermarks; and inspect or edit supported metadata.
- **Sound and music:** play supported recordings, MIDI and older music formats; convert audio; trim recordings; and combine files.
- **Video:** view supported videos, convert formats, trim, crop and rotate footage, extract sound, and save individual frames as pictures.
- **PDFs and documents:** read supported documents, rearrange PDF pages, extract pages as images, and turn scanned PDFs into searchable documents using text recognition.
- **Text and code:** read and edit text files, work with Markdown and HTML, search and replace text, and view programming languages with coloured syntax.
- **Archives and folders:** browse their contents, extract supported archives, create ZIP files, and get a summary of the kinds of files in a folder.
- **Specialist and historical files:** explore supported e-books, email collections, database tables, fonts, disk images, 3D models and other less common formats.

The tools offered depend on the files you select. Support varies between formats: being able to view a file does not necessarily mean it can be edited or converted. Some older formats have several variations, and damaged or protected files may not open.

## Getting started

1. Download a Windows package from [Releases](https://github.com/grahamlgrove/groves-pocketknife/releases), when available.
2. If the download is a ZIP file, extract it into a folder first. Keep the application and its accompanying files together.
3. Open `Pocketknife.exe`.
4. Drag files or folders into the window, or use **Choose files** or **Choose a folder**.
5. Select the items you want to work with, then choose a tool. Check its options and where the result will be saved before starting.

Many tools let you work with several files at once. New copies are the usual default; tools that support replacing an original offer an overwrite option. Keep a backup of valuable originals when trying unfamiliar operations.

Longer tasks appear in the Jobs window, so you can follow their progress while continuing to view other files.

## Try it free

Pocketknife provides **seven days of full access**. After that, you can continue viewing files for free and perform **three successful file-changing jobs each day**. A batch operation counts as one job. A full licence will be available for a one-time fee through the [Pocketknife website](https://grove.id.au/software/pocketknife/) once the release and checkout are ready. There is no subscription or ongoing cost.

- **Personal use:** install it on any number of your own computers.
- **Business use:** one licence covers up to five computers. Buy another licence for each additional group of up to five.
- **Updates:** your licence includes future updates within the major version purchased. Future major versions may be separate purchases.
- **Activation:** enter your purchase email address and the licence code emailed to you. Activation works offline.
